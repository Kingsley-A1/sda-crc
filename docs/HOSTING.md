(Same instructions are available in ASSETS/PROTOTYPE/HOSTING.md)

1. Make sure `docs/` contains:
   - `index.html`, all HTML pages you want to publish
   - `styles.css`
   - `logo.svg` (or `logo.png` if you prefer — copy the original file into `docs/`)

2. In your GitHub repository settings enable Pages from branch `main` (or your branch) and set folder to `/docs`.

3. Visit https://<your-username>.github.io/<your-repo>/ after a minute.
